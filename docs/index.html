The shared core of the font tools

FontCore is the code every font tool here shares: the console output, how fonts are found, how filenames are read, and the naming rules. It is why the tools look alike and agree on what a name should be.

You don't install FontCore. Each tool carries its own copy of the parts it uses, so installing a tool is one step. This site is for people changing FontCore or the naming rules, and for anyone who wants to know why a tool named a font the way it did.
