Working on FontCore

Developing

Change FontCore here, never in a tool's vendored copy.

cd FontCore
python3 -m pip install -e ".[dev]"
pytest

What the tests enforce

  • Fonts keep their modified time. fontTools stamps the current time on every save unless the font was opened with recalcTimestamp=False. A test fails when a TTFont(...) open leaves the flag out.
  • Python 3.10 or newer, with fonttools and rich only.
  • The naming rules, one test file per decision (compounds, weight words, ID 2, no-style files). A rule change starts with a failing test.

Releasing

  1. VersionBump version in pyproject.toml and src/FontCore/__init__.py.
  2. TagCommit, then tag vX.Y.Z with a one-line note. If names change, say so.
  3. Sync the toolsSee how tools use it.

Wording

The words people read (help text, messages, prompts, docs) follow .claude/skills/cli-writing/SKILL.md: who the reader is, the voice, standard flag wording and preferred terms. It applies to every tool in the set.
