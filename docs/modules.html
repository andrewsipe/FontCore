Modules

Everything lives in src/FontCore/ as core_*.py. A tool vendors only the modules it uses and the ones those import.

Console and errors

ModuleWhat it does
core_console_stylesStatus labels, tables, panels and progress bars; the shared before-and-after messages and prompts. Falls back to plain text without Rich.
core_console_configThe console theme, labels and settings.
core_cli_helpBuilding blocks for --help screens.
core_error_handlingTracks errors across a batch and reports them.
core_logging_configLogging setup and verbosity.

Finding and reading fonts

ModuleWhat it does
core_file_collectorFinds TTF, OTF, WOFF and WOFF2 files, with or without subfolders.
core_font_extensionDetects the real format from the file's first bytes and checks the extension.
core_font_metadataReads PostScript name, version, vendor ID and format.
core_font_utilsValidates PostScript names and cleans folder and file names.
core_font_sorterGroups fonts into families and sorts by weight, width and style.
core_variable_font_detectionFinds variable fonts, their axes and instances.

Names

ModuleWhat it does
core_filename_parts_parserSplits a filename into family and style.
core_variable_filename_parserThe same for variable fonts, including the older filename layouts.
core_font_style_dictionariesWeight, width and modifier words; joins compounds; adds a missing Regular.
core_name_policiesBuilds IDs 1, 2, 4, 16 and 17 and decides ID 2 (see naming rules).
core_nameid_replacer_baseThe shared run for every fontnameid command: plan, confirm, write, summarize.
core_namerecord_matcher / _writerFind and write Windows English name records in binary fonts and TTX.
core_nameid_allocatorAllocates name IDs for variable-font axes and instances.
core_name_attributionResolves copyright and trademark text.
core_string_utilsEmpty-string and joining helpers.

Tables and features

ModuleWhat it does
core_ttx_table_ioReads and writes font tables as TTX.
core_stat_builderWrites STAT axis values and named instances.
core_gpos_repairGPOS repairs needed before the variable-font instancer.
core_ot_label_scanner / _reflow / _suggestFind, move and suggest labels for stylistic sets and other features.
core_metadata_catalogLooks up family metadata in a JSON catalog.
